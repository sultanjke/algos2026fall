|  |  |
| --- | --- |
| **Time limit:** | 1 s |
| **Real time limit:** | 5 s |
| **Memory limit:** | 256M |

### Problem D: Calendar

You’re given n dates in format DD−MM−YYYY. Sort them in ascending and print in te same format.

### Input format

The first line contains one integer n (1≤n≤103). Next n lines contain dates in format DD−MM−YYYY (1≤D≤31,1≤M≤12,1900≤Y≤3000). Every date is a valid calendar date.

### Output format

Print sorted dates in the same format as the input.

### Examples

#### Input

```
3
01-12-2000
01-11-2000
31-10-2000
```

#### Output

```
31-10-2000
01-11-2000
01-12-2000
```

#### Input

```
4
01-12-1999
12-11-2002
20-02-1900
31-01-1999
```

#### Output

```
20-02-1900
31-01-1999
01-12-1999
12-11-2002
```
