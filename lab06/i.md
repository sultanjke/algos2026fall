## Submit a solution for I-Problem C. Azat likes sorting

|  |  |
| --- | --- |
| **Time limit:** | 1 s |
| **Real time limit:** | 5 s |
| **Memory limit:** | 256M |

### Problem I: Problem C. Azat likes sorting

Azat is a perfectionist and he likes everything to be perfect. Help Azat sort letters alphabetically. good luck!

### Input format

The only line contains the string s of lowercase Latin letters (1≤|s|≤106).

### Output format

Print the letters of s in non-decreasing alphabetical order.

### Examples

#### Input

```
qwertyuioplkjvbn
```

#### Output

```
beijklnopqrtuvwy
```

### Notes

Try to sort the letters yourself instead of calling the library sort — at the defence you will be asked to do exactly that.
