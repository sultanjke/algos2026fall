## Submit a solution for E-Incomplete sorting

|  |  |
| --- | --- |
| **Time limit:** | 1 s |
| **Real time limit:** | 5 s |
| **Memory limit:** | 256M |

### Problem E: Incomplete sorting

You are given matrix with n rows and m columns.

You have to sort each column of matrix in descending order.

### Input format

The first line consists of two integers n and m (1≤n,m≤100) — the number of rows and columns of the matrix respectively.

Each of the next n lines contains m integers di,j (−109≤di,j≤109) — elements of the matrix at the intersection of the i\-th row and the j\-th column.

### Output format

Print this matrix after sorting.

### Examples

#### Input

```
4 3
1 2 3
4 5 6
6 7 8
9 8 7
```

#### Output

```
9 8 8
6 7 7
4 5 6
1 2 3
```
