## H. Splitting

Time limit: 2 s · Memory limit: 256 MB

Given a string s, calculate the number of ways to divide s into 3 non-empty strings a,b,c such that: a+b+c\=S and a+c\=b+c

Input

You are given the string s (1⩽|s|⩽5⋅106), consisting of small Latin letters.

Output

Print the number of ways to partite string.

Note

String from the first testcase can be partitioned in two ways:
1\. _ab_ + _ab_ + _ababcx_
2\. _abab_ + _abab_ + _cx_

Examples

**Input 1**

```
ababababcx
```

**Output 1**

```
2
```
