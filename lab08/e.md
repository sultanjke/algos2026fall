## Submit a solution for E-Distinct substrings

|  |  |
| --- | --- |
| **Time limit:** | 4 s |
| **Real time limit:** | 8 s |
| **Memory limit:** | 256M |

### Problem E: Distinct substrings

Given string s. How many different substrings it contains?

### Input format

The only line contains string s (0≤|s|≤2000), consisting of lowercase Latin letters. The string may be empty.

### Output format

Print one integer — the number of distinct substrings of s. The empty substring is not counted.

### Examples

#### Input

```
aab
```

#### Output

```
5
```

#### Input

```
abcde
```

#### Output

```
15
```

### Notes

You can solve this problem using hashes. Naive O(N3) solutions must fail.
