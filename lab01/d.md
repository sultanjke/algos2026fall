### Problem D: Prime Numbers

Recall that a **prime number** is an integer greater than 1 that has exactly two positive divisors: 1 and the number itself. Written in increasing order, the prime numbers form the sequence 2,3,5,7,11,13,17,…

Given an integer n, print the n\-th number of this sequence.

### Input format

The only line contains a single integer n (1≤n≤1000).

### Output format

Print a single integer — the n\-th prime number.

### Examples

#### Input

```
5
```

#### Output

```
11
```

### Notes

The prime numbers in increasing order are 2,3,5,7,11,13,…, so the 5\-th of them is 11.

Do not confuse the index with the value: the 100\-th prime number is 541 and the 1000\-th is 7919. Every answer fits into a 32-bit integer.
