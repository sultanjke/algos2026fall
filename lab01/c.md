### Problem C: Prime or Not

Asman is very curious and likes to check whether a number is prime or not.

Recall that a **prime number** is an integer greater than 1 that has exactly two positive divisors: 1 and the number itself. In particular, 1 is not prime, because it has only one positive divisor.

Given an integer a, determine whether it is prime.

### Input format

The only line of the input contains one integer a (1≤a≤106).

### Output format

Print “`YES`” (without quotes) if a is prime, and “`NO`” (without quotes) otherwise.

### Examples

#### Input

```
1
```

#### Output

```
NO
```

#### Input

```
10
```

#### Output

```
NO
```

#### Input

```
2
```

#### Output

```
YES
```

#### Input

```
97
```

#### Output

```
YES
```

### Notes

In the first example a\=1. It has only one positive divisor, so it is not prime.

In the second example 10\=2⋅5 is composite.

In the third and fourth examples 2 and 97 are prime.
